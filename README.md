# skolifappen.se

## Välkommen till Skol IF-appen!
Just nu bygger vi för fullt på den digitala plattformen för Skol-IF-verksamheten i Sverige.

* **Unga leder unga:** Fokus på föreningsliv, ledarskap och gemenskap för elever i skolan.
* **Aktiviteter och utbildningar:** Håll utkik efter kommande händelser.

Sidan uppdateras löpande inom kort.
