🔐 Snabbguide: Konton & Firestore Security Rules

Lägg upp dessa 3 användare i Firebase Console → Authentication → Users (med valfria lösenord som du skickar till respektive distriktsledare):

  • Jämtland / Härjedalen: jamtland@skolifwebben.se
  • Medelpad: medelpad@skolifwebben.se
  • Ångermanland: angermanland@skolifwebben.se
  • Admin (Du): tobias.sellin@gmail.com (via Google-inloggning)

Lägg till följande block inuti match /databases/{database}/documents { ... } under Firestore Database → Rules: 

function isAnmalanAdmin() {
  return request.auth != null && request.auth.token.email == 'tobias.sellin@gmail.com';
}
function isDistrictOwner(districtId) {
  return request.auth != null && (
    (districtId == 'jamtland' && request.auth.token.email == 'jamtland@skolifwebben.se') ||
    (districtId == 'medelpad' && request.auth.token.email == 'medelpad@skolifwebben.se') ||
    (districtId == 'angermanland' && request.auth.token.email == 'angermanland@skolifwebben.se')
  );
}
function isAnmalanOpen() {
  return !exists(/databases/$(database)/documents/utbildning_anmalan/_config) ||
         get(/databases/$(database)/documents/utbildning_anmalan/_config).data.isLocked != true;
}
match /utbildning_anmalan/_config {
  allow read: if isAnmalanAdmin() || isDistrictOwner('jamtland') || isDistrictOwner('medelpad') || isDistrictOwner('angermanland');
  allow write: if isAnmalanAdmin();
}
match /utbildning_anmalan/{districtId} {
  allow read: if isAnmalanAdmin() || isDistrictOwner(districtId);
  allow create, update: if isAnmalanAdmin() || (isDistrictOwner(districtId) && isAnmalanOpen());
  allow delete: if isAnmalanAdmin();
}
